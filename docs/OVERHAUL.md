# Plant overhaul

Goal: a pressurized-water plant the player builds, wires and operates: moving rods, bound controls and instruments, a real cooling tower, a turbine that drives Create machinery, and accidents that grow out of the simulated state.

## What stays

- **Vessel:** casing shell with fuel, control and coolant columns in any valid size, the controller, ports, per-block diagnostics and casing integrity.
- **Process state:** `CoolantBuffer` carries fluid, heat, phase and pressure. Splits and merges conserve mass and heat. Create transfers keep heat between coolant machines.
- **Circuits:** the Circulation Pump traces a single-path loop and moves coolant through every tank and pipe on it. Pipes hold coolant, and hot coolant bursts ordinary Create pipes.
- **Fuel lifecycle, radiation, contamination and shielding.**

## What changes

| Area | Before | After |
| --- | --- | --- |
| Turbine | Fixed 16 RPM, takes 2% of steam energy every tick whatever the load | Rated speed set on the turbine. A governor valve follows the shaft load, with rotor overspeed and an overspeed trip on sudden load loss |
| Electricity | None | None of its own: the turbine shaft drives Create machinery, and an addon such as Create Crafts & Additions can turn it into Forge Energy |
| Control rods | Drive holds a number | Visible rod assembly that travels with the real insertion, rod banks, bank controls |
| Inspection | Goggles only | Vessel viewport block; rods and fuel glow visible through it |
| Controls | Redstone on the controller and drives | The Reactor Alloy Dashboard with buttons, switches, levers, gauges and alarms bound straight to plant machines or to Redstone Links, each with a settings screen. Reactor Signal Interfaces do the same from redstone pulses |
| Primary pressure | None (liquid coolant has no pressure) | Pressurizer on the primary loop: heaters, spray, relief; low pressure lets coolant boil in the core |
| Cooling tower | Stack of packing blocks | Built tower: fill standing on its outlet pipe, the hot inlet in the side of the top block, make-up water piped into the fill, a Create Encased Fan on top, driven through the fill's own shaft; stacked fill joins into one glazed column that shows its water level; capacity from fill, water and airflow; makeup water and evaporation |
| Feedwater | Loop pump only | A Create Fluid Tank inline in the loop, with a make-up pump |
| Reactivity | Rods and fuel only | Fuel-temperature and coolant-temperature feedback; operating modes with start-up permissives |
| Accidents | Trip, cracks, breach leak | Fuel damage, clad failure, core melt, corium, burn-through, wreckage and contaminated blocks that persist |
| Guidance | README | Ponder scenes, reference plant function |

## Phases (dependency order)

1. **A. Energy chain.** Turbine governor and overspeed. The Generator built in this phase was later removed: the shaft is the output.
2. **B. Rods and inspection.** Visible rod travel, banks, viewport.
3. **C. Controls and instruments.** Dashboard and parts, part settings, Signal Interface jobs, alarm signal.
4. **D. Plant equipment.** Pressurizer, feedwater tank, built cooling tower with fans.
5. **E. Reactor behaviour.** Temperature feedback, operating modes, permissives, protective trips through installed equipment.
6. **F. Accidents.** Progressive core damage, corium, persistent wreckage, config limits.
7. **G. Guidance.** Ponder scenes, reference plant, end-to-end scenario tests.

## Status

- **A to F:** on main, each with game tests and an in-game check.
- **G:** the operating manual is `docs/OPERATING.md`, the reference plant is generated by `src/inspect/scenes/make_facility.py`, and `plantStartsRunsGeneratesAndShutsDown` is the end-to-end scenario test.
- **Control room:** a linked wall of Plant Screens shows the reactor display with trends and events, Display Link sources feed smaller walls and Create displays, and the controls are Reactor Alloy Dashboards with parts bound to the plant. `src/inspect/scenes/make_control_room.py` runs the reference plant from its desk.
- **Create-first pass:** the mod's own tanks, tower distributor, tower fan, fuel bench, alarm siren, generator and breaker panel are gone. Loops run through Create's pipes and Fluid Tanks, hot runs are reinforced in place with a Reactor Alloy Ingot, the turbine shaft is the output, screens run on rotation and the Pressurizer on a Blaze Burner. A Centrifuge adds enrichment to the fuel chain.
- **Not done:** Ponder scenes. Feedwater equipment is a surge tank only. Brackets do not render on Reinforced Pipe. Rod banks are set with buttons; there is no analog bank lever. Automatic rod regulation is left to player-built gauge and button wiring.

Each phase lands with game tests and an in-game check before the next starts. Saves: existing blocks keep their ids and data; new state defaults to the old behaviour when absent.

## Units

- Heat: HU. Water: 1 HU per mB per °C, boils at 80 HU/mB above ambient, 540 HU/mB latent.
- Shaft power: SU. 1 HU/t of steam work is 4 SU.
